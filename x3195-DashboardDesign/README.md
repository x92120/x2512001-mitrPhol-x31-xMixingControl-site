# Mitr Phol Advanced SCADA Dashboard Design

This is a premium, high-fidelity UI concept for the Mitr Phol Mixing Control system. It is designed to provide operators with a "Glass Cockpit" experience, combining real-time telemetry with intuitive process visualization.

## Design Philosophy
- **Glassmorphism:** Using semi-transparent surfaces to create depth and focus.
- **Neon-Industrial:** High-contrast colors (Cyan, Green, Orange) on a dark background for maximum readability in plant environments.
- **SVG Process Flow:** Real-time animated diagram of tanks, silos, and pipes.

## Key Features
- **Animated PFD:** Visualizes liquid levels and agitator rotations.
- **Responsive Metrics:** Real-time gauges for critical process variables (Temperature, Level).
- **Integrated Alerts:** Color-coded system health logs.
- **Control Interface:** Quick-action buttons for Auto/Manual switching and Emergency stops.

## Technical Stack
- **Frontend:** HTML5, CSS3 (Flexbox/Grid), SVG.
- **Typography:** Outfit (Heading), JetBrains Mono (Data).
- **Animations:** CSS Keyframes & SVG `animateTransform`.

## How to View
Open `index.html` in any modern web browser.
